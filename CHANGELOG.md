# История изменений (Changelog)

Все заметные изменения в проекте **WoW Updater** будут документироваться в этом файле.

## [v1.0.1] - 2026-06-07
### 🐛 Исправлено (Bug Fixes)
- **Критический баг подбора версий (Raider.IO / WeakAuras):** Исправлена логика автоматического скачивания аддонов для старых патчей. 
  - *Проблема:* Ранее загрузчик скачивал самую последнюю версию из доступных в категории Retail (из-за чего для патча 11.x ошибочно скачивались сборки под Midnight 12.x).
  - *Решение:* Логика ядра `downloader.py` переписана. Теперь программа выполняет **строгий текстовый поиск** по патчу (например, `11.0.5`), указанному в настройках. Если точное совпадение найдено, скачивается именно этот файл, полностью игнорируя версии для Midnight. Общие фильтры применяются только как запасной вариант (fallback).

## [v1.0.2] - 2026-06-07
### 🚀 Добавлено (Features)
- **Строгий фильтр будущих версий (Strict Versioning):** Ядро загрузчика (`downloader.py`) переработано. Если указана точная версия патча (например, `11.1.7`), программа теперь *полностью* игнорирует файлы, содержащие теги более новых версий (например, `11.2.0` или `12.0.0`). Это гарантирует, что скачанный аддон точно не содержит "спойлеров" или контента из будущих сезонов.
- **Предупреждения о fallback-заменах:** Если для выбранного аддона не найдено точной версии, программа подберет самую свежую из безопасных (не превышающих ваш патч) и выведет об этом красивое предупреждение в консоли приложения.
- **Умный поиск и пагинация в окне версий:** 
  - Лимит сканируемых файлов CurseForge увеличен с 200 до 1000 для охвата более старых версий.
  - В окне ручного выбора "Версии" добавлена удобная строка поиска.
  - Окно теперь отображает максимум 50 результатов за раз, чтобы избежать зависаний интерфейса из-за огромного объема истории.

## [v1.0.0] - 2026-06-07
### 🚀 Добавлено (Features)
- **Релиз скомпилированной версии:** Программа впервые упакована в standalone `.exe` файл. Больше не требуется установленный Python для работы приложения!
- **Ручной выбор версий аддона (Downgrade):**
  - Добавлена кнопка **"Версии"** напротив каждого аддона (в поиске и списке установленных).
  - По клику открывается новое окно со списком последних 200 сборок аддона с серверов CurseForge.
  - Позволяет откатываться на старые стабильные сборки в обход глобальных настроек (незаменимо, если разработчик сломал новую версию аддона под ваш клиент игры).
  - Добавлено предупреждение в `README.md` о необходимости ввода команды `/reload` после ручного отката.
- **Премиум дизайн репозитория:**
  - Полностью переписан `README.md`.
  - Сгенерирован стильный логотип проекта.
  - Добавлены интерактивные бейджи и приятная навигация по репозиторию.
- **Автоматизация GitHub Actions:**
  - Настроен пайплайн `.github/workflows/release.yml` для автоматического прикрепления `.exe` файлов при выпуске новых тегов.
