# WoW Updater

![App Icon](app.ico)

**WoW Updater** — это легковесный, быстрый и портативный менеджер аддонов для World of Warcraft. Он создан как минималистичная альтернатива перегруженному официальному клиенту CurseForge. Никакой рекламы, никаких фоновых процессов — только чистый функционал в одном `.exe` файле.

## Особенности 🌟
- **Стильный дизайн**: Темная тема в стиле оригинального CurseForge с современным боковым меню.
- **Умное скачивание**: Полная поддержка автоматического разрешения и установки зависимостей аддонов.
- **Клонирование сборок**: Возможность в один клик перенести чужую папку `AddOns`, распознать все аддоны и автоматически докачать свежие версии и отсутствующие библиотеки с CurseForge!
- **Портативность**: Вся конфигурация хранится рядом с файлом программы (в `config.json` и `state.json`), поэтому вы можете закинуть программу на флешку вместе с аддонами.
- **Очистка от мусора**: Локальные аддоны, которых нет на CurseForge, автоматически группируются в самом низу списка, где вы можете удалить их в один клик.

## Установка и запуск 🚀

Вам не нужно устанавливать программу. Просто скачайте готовый `WoW Updater.exe` из раздела **Releases**.

1. Запустите `WoW Updater.exe`
2. Перейдите на вкладку **Настройки**
3. Введите ваш **CurseForge API Key** (можно получить [здесь](https://console.curseforge.com/))
4. Укажите путь к папке `_retail_\Interface\AddOns` (или к любой другой нужной версии игры).
5. Выберите вашу версию игры из списка (поддерживаются все актуальные версии, включая The War Within, Midnight, Cataclysm Classic, Classic Era).

## Сборка из исходников 🛠️

Если вы хотите собрать `.exe` файл самостоятельно:

1. Установите Python 3.10+
2. Установите зависимости:
```bash
pip install customtkinter pillow requests undetected_chromedriver selenium pyinstaller
```
3. Скомпилируйте программу с помощью PyInstaller:
```bash
python -m PyInstaller --noconfirm --onefile --windowed --icon="app.ico" --add-data="app.ico;." --name "WoW Updater" WoW_Updater_Source.py
```
Скомпилированный файл появится в папке `dist`.
