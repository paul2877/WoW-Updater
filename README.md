## Инновации в каждой строке кода.

Мы переосмыслили то, как вы управляете аддонами. Никакого визуального шума. Только то, что действительно важно.

* **Умный поиск.** Мгновенный доступ к базе CurseForge прямо из приложения. 
* **Time Machine.** Ваш любимый аддон сломался после обновления? Возвращайтесь к предыдущей версии в один клик. Идеально для кастомных патчей и приватных серверов.
* **Магия профилей.** Разделяйте сборки для PvP и PvE. Легко экспортируйте и делитесь с друзьями.
* **Локальное сканирование.** Программа автоматически найдет ваши текущие аддоны и бесшовно возьмет их под свое управление.

<br>

## Начать работу — проще простого.

Вам не нужно ничего устанавливать или компилировать. Всё уже готово к работе из коробки.

1. Зайдите в раздел **[Releases](https://github.com/paul2877/WoW-Updater/releases)** и скачайте `WoW_Updater.exe`.
2. Запустите приложение.
3. Откройте **Настройки (⚙️)** и укажите:
   * Путь к папке игры (например, `...\_retail_\Interface\AddOns`)
   * Ваш бесплатный API ключ CurseForge. Получить его можно на [console.curseforge.com](https://console.curseforge.com/), создав ключ во вкладке **API Keys**.

<br>

## Если что-то пошло не так.

Если после обновления аддона (например, WeakAuras) в игре появляются ошибки LUA, воспользуйтесь функцией отката:

1. Откройте **Мои аддоны**.
2. Выберите нестабильный аддон и нажмите **[Версии]**.
3. Установите предыдущий стабильный релиз.
4. Разверните игру и введите `/reload` в чат.
